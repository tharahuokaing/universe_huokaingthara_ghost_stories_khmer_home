## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_ghost_stories_khmer_home`** is the dedicated home portal for **និទានរឿងខ្មោចខ្មែរ (Ghost Stories Khmer)** under **UNIVERSE HUOKAING THARA Group**. It brings together Khmer supernatural folklore, real-life eerie encounters, and midnight episodes narrated and contributed alongside **Mr. Chorn Rothanak**.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔎 Live Story Search & Category Filtering:** Filter episodes by category (*Folklore, Real Experience, Midnight Special*) or search by title, theme, or keyword in real time.
* **☠️ Scare Level & Runtime Badges:** Quick visual indicators showing episode scare ratings (*High Scare / Medium Scare*) and runtime duration.
* **📖 Interactive Story Preview Modal:** Open an episode preview dialog displaying the story title, narrator/contributor credit, and atmospheric opening excerpt.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់

- **Frontend Core:** Semantic HTML5, CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (`Kantumruy Pro` for Khmer script, `Poppins` for English UI)
- **Icons:** FontAwesome v6.4.0
- **UI/UX Design:** Cyberpunk Holographic Dark/Light Theme with Scanline Overlay
